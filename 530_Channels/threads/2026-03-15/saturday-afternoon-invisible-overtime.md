你以為 side project 是休息，其實它是你最精緻的加班。

週六下午，你本來打算放空。結果「看一下」就打開筆電，三小時後才抬頭——你甚至沒有罪惡感，因為這不是老闆叫你做的，是你自己想做的。

但問題就在這裡。

Side project 讓人停不下來，正因為它長得不像工作：

**自己選的，所以沒有罪惡感**
沒人逼你、沒有 deadline，你連「我應該休息」的警鈴都不會響

**換了內容，但沒換大腦**
寫不同的 code 不是休息，你只是從 A 賽道換到 B 賽道繼續跑，認知資源一樣在燒

**「什麼都不做」不會自己發生**
對創造者來說，空白要像會議一樣排進行事曆，不排，它永遠不會出現

問自己一個問題：你上一次真正什麼都沒做的週末，是什麼時候？

答不出來的話，那就是答案了。
