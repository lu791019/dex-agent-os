- 達到知識複利的兩個條件：
    - 不能有遺忘：忘了就是負損(浪費時間學，忘了又浪費時間再次去看)
    - 相關知識的累積：若兩者沒有關係，沒有1+1>2
- 知識複利筆記術：
    - 原始素材
    - 拆分主題筆記
    - 2W1H → 觀念連結(數位筆記)
        - What 事實
        - Why 原理
        - How 應用
    - 進行歸納

- 知識變現的兩個策略
    - ROA理論
        - Reader 讀者：設想跟定位讀者的樣貌與閱讀情境
            - 有共鳴的經驗
            - 多用“你”
        - Objective 目的：想要傳達什麼或想要改變什麼想法
        - Action 行動：期待閱讀完有什麼行動
    - OEC理論
        - Opinion 主張：對議題的看法，認為事情應該是怎麼樣
        - Evidence 論證：為什麼會這樣想，有什麼依據？
        - Conclusion 結論：對此有什麼呼籲，希望大家做什麼？
            - 格言美肌法
            - 格言顛覆法
- 個人品牌四個思考
    - 經營聲譽，名聲 = 性格＋專業(職涯初期奠定自身品牌)
    - 不要做網紅，要做專家（不要把價值建構在他人認同）
    - 深耕專業終會被看見（培養專業能力）
    - 思考如何衡量自身價值（能帶來多少正面影響）
- 知識價值轉換：知識落差，資訊落差
    - 知識複利就是知識剩餘價值再利用
    - 斜槓組合（也是知識產品化的過程）：寫作＋教學＋演講＋顧問：
        - 專業知識 or 獨特經驗 → 延伸成產品與服務 → 變現為：
            
            1. 社交貨幣（品牌名聲,異業合作,人脈）
                
            2. 金錢貨幣：課程收費
                
- 初期目標：能幫助本業的副業，需注意
    - 脫離戰場(職場)，導致知識更新變慢
    - 知識變現風險高且需長時間經營
- BAR變現枝枒：
    - Benefit 利益：希望幫助學員的成果是什麼？成果越清楚，知識產品設計會越明確。
    - Audience 受眾：需要這個成果的客戶是什麼？(TA)
        - 受眾的衡量從行為 感受，需要同理心與想像力
        - 思考受眾是1.新手 2.老手，因兩者狀態不同，預設為新手最保險
        - 思考想像的客戶是否符合提供的成果（可能成果超過客戶的需求）
        - 會經過幾次市場回饋更清楚
    - Reasons:
        - 以需要為主的推力：SEO
        - 以想要為主的拉力：口碑行銷(信任飛輪，如電子報)
- CTA變現行動
    - C : 教練或顧問
    - T : 教學或工具
    - A : 知識產品：文章,影像,聲音：可做免費分享或當作補充包，累積信任資產
    - 做法
        - T X C : 流程化的課程或工具做為核心，引導客戶進行客製化專案
        - T X A：流程系的課程或工具轉變為固定的知識產品
            - 以課程為主體的產品
            - 以產品為主體的課程
