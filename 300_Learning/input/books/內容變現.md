## My Thoughts

- RISE :
- IPOD :
    - Interest and Passion：興趣熱情，刻意練習
    - 最重要的事
    - Professional Skills：專業技能 ，知識萃取
    - Outcome Based Solution：解決方案/服務方案，服務變現
    - Decent Value：相應價值
- 知識複利過程
    - 經驗知識 → 知識展品化：知識架構 → 產品設計 → 知識產品 → 知識變現
    - 困難問題 → (探索解決)
    - → 品質型知識複利 (深度X廣度X速度) :
        - 經驗知識(應用解決問題，一般人停在這) → (輸出整理) → 知識架構
    - → （產品設計）
    - → 價值型知識複利 (一源多用 X 一本多利)：
        - 知識產品
            - 服務型：教練 顧問 專案
            - 教育型：課程 工具 流程
            - 內容型：文章 影片 影音
    - → ( 變現模式 )
    - → 知識變現
- 知識複利 & 知識型個人品牌：以知識工作者個人為基礎的品牌
    - 可辨識：辨認品牌屬於某個領域
    - 可信任：信任品牌提供的產品與服務
    - 可認同：認同品牌的價值與理念
    - 太著急：未想清楚淺在TA，缺乏足夠專業，沒有信任感
    - 太貪心：
- 以商業基底與內容創作的POEM法則：
    - Preparation 預備期
        - 用產品設計思維去思考自身定位
        - 賣給誰？賣什麼？獨特性？
        - 我能為我的受眾以內容創作的方式帶來怎樣的解決方案
        - 定義自己的願景，希望被定位成怎樣的創作者
        - “透過內容創作，1~3年能達到怎樣的境界”
        - 搞懂遊戲規則：有哪些其他的玩家和競爭者，又是用怎樣的形式參與這場“無限賽局”，回推自己的定位是否能讓用戶記住
        - 用戶分析 Persona 價值主張 商業模式畫布 STP 競品分析
    - Operation 營運期
        - 冷啟動：從0到1
        - 決定內容的形式：不要橫跨太多平台跟形式，專心做好其中一種，以一個平台為主，另2-3個搭配。
        - 未有起色：
            - 營運一季且是次要平台，果斷放棄。
            - 主要平台則思考調整方向
        - 產出需要好的時間規律
        - 一個可以長期維持的更新頻率：每週 1-2 次
        - 專案管理 時間四象限 沈沒成本 內卷化理論 顧客價值管理
    - Expansion 價值擴張期
        - 透過行銷讓影響力擴張
        - 思考粉絲和點閱數對於影響力的增加程度
        - 是否有因為內容創作提高影響力：被領域專家關注，領域夥伴或單位邀請
        - 以商業開發的角度與外部提案洽談
        - 向外延伸&向下扎根：受眾關係經營
        - 行銷方法與工具，放大影響力
        - STV模型 商業開發 滾雪球效應 DARGMAR模式 LAST原則
    - Monetization 價值轉換期
        - 從流量跟影響力轉換為實際價值 → 變現，DCK模式
            - 直接變現(Direct Monetization)：廣告分潤 付款打賞
                - 困難，非常吃流量和粉絲喜愛程度
            - 協同行銷(Collaborative Marketing)：業配 聯盟行銷
                - 追求導流效果：流量轉換成合作夥伴的購買
                - 依照品牌調性去思考，彼此在議題關注跟形象上對於受眾來看有一至性
            - 知識產品(Knowledge Product)：課程 顧問 訂閱 出版
                - 直接從受眾作為主體帶來價值轉換
                - 不會受到演算法綁架，主控權高
                - 線上課程或個人訂閱制
                - 定價策略 MAN法則 FAB法則 策略思維
