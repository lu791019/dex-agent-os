# 「人類定義好，機器跑迭代」是通用模式

Autoresearch 的本質不是 ML 優化工具，而是一個通用框架：只要你能把「好」定義成 yes/no 問題，AI 就能幫你跑 50 輪你永遠不會手動做的迭代。廣告文案、email、Skill 檔案、影片腳本都適用。

## 潛在切入角度
Threads 用「你還在手動改 prompt 嗎？Karpathy 一晚 100 輪、$25 自動迭代」的反差開場，拆解三檔案機制 + 適用條件。Newsletter 可以做完整的 6 個應用場景指南。
