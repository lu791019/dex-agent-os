# 靜態 eval vs 動態 eval：AI 迭代的兩種層次

Autoresearch 用固定 binary 標準自動迭代（靜態 eval），適合結構明確的任務。但寫作品質這種主觀產出，更適合「人類專家審核 → 萃取審核差異 → 存進系統」的動態 eval — 讓品質標準本身也在進化。兩者可以結合：靜態 eval 跑基礎迭代，動態 eval 升級評分標準。

## 潛在切入角度
Threads 用「AI 自動改 prompt 很酷，但誰來定義什麼是好的？」切入，對比兩種 eval 模式。適合工程師和 AI 創作者族群。
