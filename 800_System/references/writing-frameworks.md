# 寫作框架收集

> 跨頻道的論述公式與文案結構。寫文前可翻閱，挑一個適合當前主題的框架套用。
> 持續累積中，每個框架附上：結構、適用場景、範例。

---

## 1. 不是錯覺框架

**結構**

```
如果你發現 [問題]，不是錯覺、也不是 [迷思]，是 [真相]：

- 建議 1
- 建議 2
- 建議 3
```

**邏輯**：先驗證讀者的感受（「你沒有想錯」），再破除常見誤解，最後給出真正的原因和行動建議。三段式：共感 → 破迷思 → 給方向。

**適用場景**
- 職涯焦慮類（升遷卡住、技能過時、薪資天花板）
- 技術認知類（工具選錯、架構誤區、效能迷思）
- 任何「讀者隱約感覺到問題但說不清楚」的主題

**範例**

> 如果你升到 Senior 之後開始覺得卡住，不是錯覺，也不是技術退步，是你還沒意識到一件事：你的角色已經變了。
>
> - 不要只看技術，要開始看「成本」
> - 不要只記住系統，要理解「設計原則」
> - 開始成為成本的守門人

**變體**
- 可以把「建議」換成「觀察」或「真相的不同面向」
- 收尾可加一句金句或開放提問
- 條列數量 3-5 條皆可，不要超過 5 條

## 2. 里程碑轉推廣框架

**結構**

```
[里程碑文] — 用一行一階段的時間軸呈現個人歷程，有高有低

[推廣文] — 從里程碑的某個轉折點，自然帶出課程/產品：
1. 回扣里程碑中的具體經歷（「我當初...」）
2. 用「如果重來 / 回頭看」翻轉成推薦理由
3. 課程細節融入敘事，不用條列規格
4. 「我自己就是講師」用「我把經歷整理成一門課」帶出
5. 收尾：溫暖但不替讀者決定（「你不用一個人摸」）
6. 折扣碼 + CTA 壓在最後一行，一句帶過
```

**邏輯**：先用里程碑建立「過來人」的信任感，再用自身經歷的痛點（走冤枉路、方向不明）作為橋樑，推薦就變成「幫你少走我走過的路」而不是「快來買」。

**適用場景**
- 課程推廣搭配個人故事
- 產品推薦需要實證基礎時
- 任何「我用過 / 我做的 / 我教的」類推廣

**關鍵原則**
- 條列課程規格 = 廣告感，融入敘事 = 朋友推薦
- 「我是講師」直說太硬，「我整理成一門課」自然帶出
- 數據（市場成長 40%）可省略，個人經驗的說服力更強
- 折扣碼不要獨立段落強調，跟連結 CTA 合併一行
- 收尾語氣：溫暖陪伴 > 硬推行動，不替讀者做決定

**範例收尾**

> 我沒辦法替你決定要不要轉，應該說，沒有人可以。但如果你現在跟當年的我一樣，在現有的工作裡覺得悶、趁空檔偷學、不確定方向對不對——至少這條路，你不用一個人摸。

## 3. 習慣累積框架

**結構**

```
你有什麼習慣，持續做了多久，帶來什麼轉變？

Hook：[習慣] + [持續時間] + [一句意外的結果]

時間軸條列（一件事一行，必須有具體情境或數字）：
- 第 X 天：[初期的笨拙 / 不適應]
- 第 X 天：[第一次感覺到變化的瞬間]
- 第 X 天：[外部可見的改變——別人的反應、工作上的差異]
- 現在：[回頭看才懂的真正價值]

收尾金句：點出「真正改變你的不是那件事本身，是 ___」
```

**邏輯**：用時間軸展開一個微小習慣的複利效應。前半段故意呈現「剛開始很廢」拉近距離，中段用具體場景讓讀者代入，收尾翻轉——改變你的不是習慣本身，而是習慣背後逼你面對的東西。

**適用場景**
- 專業成長類（每天讀技術文、寫日記、做 side project）
- 個人品牌建立（持續發文、持續學習的歷程）
- 任何「小事做久了變成大事」的主題

**撰寫重點**
- 條列呈現，一件事一行
- 必須有具體情境和數字（第幾天、幾分鐘、幾篇）
- 如果能帶到對專業領域的執著和努力過程更好

**範例**

> 每天花 15 分鐘讀一篇技術文章，已經持續 6 個月。
>
> - 第 1 週：光挑文章就花 20 分鐘，讀完也不確定重點是什麼
> - 第 30 天：開始能分辨「這篇只是舊觀念換個說法」
> - 第 90 天：開會時別人丟一個技術名詞，你已經讀過那篇了
> - 第 180 天：讀完一篇，腦中自動接上三篇之前讀過的，觀點開始長出脈絡
>
> 技術判斷力不是讀出來的，是「每天逼自己想一次」練出來的。

**變體**
- 可以混合「讀 + 筆記 + 輸出」呈現一條完整鏈
- 時間軸不一定要等距，挑「有感覺的轉折點」就好
- 條列數量 4-6 條，太少沒有累積感，太多失去節奏
- **目標宣示型**：列完現有習慣後，加上「接下來的目標」段落，暗示讀者追蹤你看後續成果。例如：「接下來的目標：每週發一篇和 XX 相關、實用到讓人想收藏的文！」——軟性 CTA，不直接叫人追蹤

## 4. 影音精華轉貼框架

**結構**

```
開頭（來源 + 量化 Hook）：
點出影片/Podcast 來源，能量化就量化（觀看數、集數里程碑、來賓頭銜）。
讓讀者一秒判斷「這值得看」。

中間（3-5 個大亮點 + 個人觀點）：
條列整理這集的核心重點，每一條用一句話概括再展開。
【關鍵】至少 1-2 條要摻入你自己的觀點、經驗或延伸思考，
不是純筆記搬運，而是「我聽完之後這樣想」。

結尾（金句收尾）：
挑一句對方說過最有力量的話收尾，或用你自己的一句話總結感悟。
```

**邏輯**：借力使力——用已有流量和公信力的內容當槓桿，加入個人觀點變成原創。讀者來看的不只是「那集講了什麼」，而是「你怎麼看這件事」。純搬運 = 筆記，加觀點 = 內容創作。

**適用場景**
- 沒靈感時的保底策略，隨時可用
- 想建立「策展人」定位（我幫你篩選值得看的內容）
- Podcast / YouTube / 訪談 / TED Talk 任何影音內容皆適用
- 想蹭話題熱度但不想只轉發的時候

**撰寫重點**
- 開頭量化：觀看次數、來賓成就、節目里程碑，讓讀者感受到「這集有份量」
- 條列為主：一個重點一段，方便速讀
- 個人觀點必加：這是吸引追蹤的關鍵——讀者要的是你的濾鏡，不是逐字稿
- 金句收尾：最好是對方原話中最有記憶點的一句，或你自己的「聽完之後我想說」
- 語氣自然：像在跟朋友說「欸我昨天聽到一集超讚的」

**範例結構示範**

> 看完 [來源人名] 在 [平台] 分享關於「[主題]」的 [影片/訪談]，
> 整理 [N] 個核心重點給大家：
>
> 1. [重點標題]：[一句話展開說明]
> 2. [重點標題]：[展開 + 個人觀點]
> 3. [重點標題]：[展開說明]
> ...
>
> [金句或個人感悟收尾]

**變體**
- **單一共鳴型**：不條列多個重點，只深挖一個最有感的觀點，用故事方式展開，適合情感共鳴類內容
- **對比反差型**：開頭用「你以為 XXX？聽完這集才知道...」製造反差，適合顛覆認知的內容
- **輕鬆隨筆型**：不刻意整理重點，而是用「無意間看到」「滑到一則」的口吻帶出，加入生活感想，適合日常風格帳號

## 5. 呼喚TA解法框架

**結構**

```
Hook（呼喚目標受眾）：
有沒有 [具體煩惱] 的人？

具體情境描述（讓讀者代入）：
用列點呈現 TA 的真實生活場景，越具體越好——
人事時地物、內心獨白、日常痛苦瞬間。

個人經歷橋接：
X 年前，我也是這樣的。後來我 [做了什麼努力]，
領悟到 N 個解法：

解法列點（3-5 條，可立即執行）：
1. [具體建議]
2. ...
3. ...

溫暖收尾：
希望能幫助跟過去的我一樣的人。
```

**邏輯**：先用精準的情境描述讓 TA 自我辨識（「這就是在說我！」），再用個人經歷建立信任（過來人），最後給出可立即執行的解法。三段式：共鳴 → 信任 → 價值。

**適用場景**
- 職涯焦慮、人際困擾、工作壓力等情緒痛點
- 技術學習卡關、職能轉換迷茫
- 任何你親身經歷過、有實戰解法的主題

**撰寫重點**
- 情境描述要「具體到像在說某個人的日常」，不是泛泛的煩惱
- 解法必須「可立即馬上執行」，不是空泛的心靈雞湯
- 「X 年前我也是這樣」是信任關鍵——你不是旁觀者，是過來人
- 收尾溫暖但不居高臨下
- 詳細解法可用「串文」逐條展開

## 6. 價值自介框架

**結構**

```
你未來會在這個帳號持續看到的價值：
- [價值/乾貨方向 1]
- [價值/乾貨方向 2]
- [價值/乾貨方向 3]

我的背景（為什麼我能給你這些）：
[簡短但有說服力的個人經歷]

我的價值觀/態度：
[一句話表達核心信念，吸引同頻的人]
```

**邏輯**：自介不是在說「我是誰」，而是在回答「追蹤你我能得到什麼」。先給價值承諾（讓人有理由追蹤），再用背景建立可信度，最後用價值觀篩選出同頻受眾。

**適用場景**
- 新帳號第一篇自介
- 追蹤數到達里程碑時的重新自介
- 任何需要讓陌生人快速理解「為什麼該追蹤你」的場景

**撰寫重點**
- 重點是「你會持續給什麼」，不是「你做過什麼」
- 價值觀要鮮明，不怕篩掉人——吸引同頻比討好所有人重要
- 背景經歷精簡帶過，不是履歷表
- 語氣像「歡迎來到我的地盤」，自信但不自大

**變體**
- **里程碑回饋型**：追蹤數破萬等里程碑，用回饋粉絲的形式重新自介 + 送福利
- **一句話型**：極簡版，一句話說完你是誰、給什麼、為什麼，適合 bio 或置頂

## 7. 年度推薦清單框架

**結構**

```
[時間範圍] 我的 [類別] 推薦：

1. [推薦項目]：[一句話為什麼推薦]
2. [推薦項目]：[一句話]
3. ...

（串文補充每一項的詳細心得）
```

**邏輯**：人天生愛看「別人的清單」——它降低了選擇成本。年度/季度推薦自帶時效性和策展感，讓你的帳號成為「可信的篩選器」。

**適用場景**
- 年度/季度/月度盤點
- 愛用 App、書單、Podcast、YouTube 頻道、工具、歌單、愛用品
- 任何可以做成「我的 Top N」的主題

**撰寫重點**
- 主文精簡列點，每項一句話就好
- 詳細心得放串文，避免主文太長
- 加入「為什麼推薦」的個人觀點，不是單純列名單
- 數量 5-10 項最適合，太少沒策展感，太多讀不完

**變體**
- **對比篩選型**：「用過 N 個 [類別]，最後只留下這 3 個」——帶有篩選故事感
- **意外發現型**：「今年最意外的發現」——強調驚喜感

## 8. 真心建議框架

**結構**

```
真心建議 [一個關鍵行動]，
你會發現 [意外的正面效果]。

[過去沒這樣做時的負面狀況，用個人經驗帶出]
```

**邏輯**：極簡結構，一句話就是一篇文。力量來自「真心建議」的懇切語氣 +「你會發現」的好處承諾 + 過去反面經驗的對比。

**適用場景**
- 生活智慧、工作心得、專業建議
- 任何「我後悔沒早點做」的事
- 適合短文、金句型貼文

**撰寫重點**
- 行動要「具體到可以馬上做」，不是「好好愛自己」這種空話
- 好處要「出乎意料」，才有記憶點
- 過去的負面經驗讓建議更有重量
- 語氣真誠，不說教

**變體**
- 可以一次列 3 個「真心建議」，變成清單型
- 收尾加一句反問（「你有沒有類似的經驗？」）拉互動

## 9. 提問爆文框架

**結構**

```
為什麼我們一定要 [社會框架/主流期待]，
卻感到 [負面情緒/真實感受]？

（主文不給答案，讓問題本身引爆討論）

【轉化策略】在留言處置頂你的獨特觀點回覆，
用爆文流量轉化為追蹤。
```

**邏輯**：戳中集體情緒的提問自帶病毒傳播力。主文不給答案是刻意的——開放式問題引發最大討論量。真正的轉化在留言區：置頂一則有深度的觀點回覆，讓被問題吸引來的人看到你的思考深度，進而追蹤。

**適用場景**
- 社會議題、職場文化、世代差異
- 任何「大家心裡想但沒人敢說」的主題
- 想衝互動量和觸及率的時候

**撰寫重點**
- 問題要「說進心坎」，不是表面抱怨
- 主文極短，一兩句就好——問題本身就是全部
- 留言置頂的觀點回覆才是你的「真正內容」
- 觀點要獨特——不是附和也不是說教，是「換一個角度看」

**變體**
- **對比型提問**：「為什麼 [A 被鼓勵] 但 [B 卻被批評]？」
- **世代型提問**：「我們這一代是不是 [某種集體困境]？」

## 10. 零成本改變框架

**結構**

```
分享一個零成本，馬上改變 [痛點] 的方法：

講重點：[一個帶有動詞的行動方案]

- 原因：為什麼這樣做有效
- 怎麼做：具體步驟

你就會立刻感覺到 [具體成效]
```

**邏輯**：「零成本」+「馬上」是雙重降低行動門檻的魔法詞。讀者最怕的不是不知道該做什麼，而是覺得太難、太貴、太花時間。這個框架把所有阻力都拿掉，讓人「看完就想試」。

**適用場景**
- 生活改善、居家整理、工作效率
- 心理健康、人際關係的小技巧
- 任何「不花錢、立刻見效」的方法

**撰寫重點**
- 行動方案要「帶動詞」——丟東西、關通知、換座位，不是「調整心態」
- 原因簡短有力，讓人知道「為什麼有效」就夠
- 成效要具體可感受，「焦慮感降低」比「會變好」有力
- 整篇不超過 10 行，極簡就是力量

**變體**
- 可以一次列 3 個零成本方法，變成清單型
- 加入「我自己試了 X 天的感受」增加說服力

## 11. 信任差異化框架

**結構**

```
我發現大家之所以信任我，是因為我的 [獨特價值/差異化]。

我幫助 [痛點 1-3] 的人，
用我 [獨有的方法]，
搭配 [價值觀/理念]，
達到 [理想的成果]。

【小技巧】轉發客戶或學員的好評，公開在社群上。
流量不大，但轉追蹤率意外地高。
```

**邏輯**：不是在推銷自己，而是在「解釋為什麼別人選擇我」——這個視角天生帶有社會證明。再加上客戶好評轉發，雙重信任加持。

**適用場景**
- 個人品牌定位宣言
- 有客戶/學員好評時的素材活用
- 需要讓潛在客戶理解「你跟別人有什麼不同」

**撰寫重點**
- 「差異化」要一句話說清楚，不是列一堆優點
- 客戶好評轉發比自己說有效 10 倍
- 語氣是「我發現」而不是「我很厲害」——觀察者視角更有說服力
- 好評轉發加一句你的感想，不是單純轉發

**變體**
- **客戶故事型**：以一個具體客戶案例展開，用故事替代條列
- **對比型**：「以前的客戶試過 [其他方法] 但 [沒效]，後來用 [你的方法]...」

## 12. 負面情緒解方框架

**結構**

```
如果你最近很 [負面情緒/狀態]，
以下 N 點值得你慢慢看：

1. [解方/觀點/提醒]
2. ...
3. ...
```

**邏輯**：精準鎖定「此刻正在經歷某種狀態」的人。「慢慢看」的語氣本身就是療癒——不急、不說教、不評判。列點提供的是情緒價值 + 實用建議的混合體。

**適用場景**
- 心理狀態：焦慮、迷茫、疲憊、自我懷疑
- 職涯困境：想離職、覺得沒成長、被否定
- 任何「讀者正在低潮，需要被接住」的時刻

**撰寫重點**
- 情緒/狀態要精準鎖定，不是泛泛的「不開心」
- 列點混合「情緒安撫」和「實際建議」，不能全是雞湯也不能全是操作
- 語氣溫暖但不居高臨下，像朋友不像導師
- 「慢慢看」「不急」「沒關係」這類詞自帶療癒感

**變體**
- **自我照顧清單型**：列出具體的自我照顧行動（好好吃飯、休息 15 分鐘、出門走走），適合極度低潮的受眾
- **身份鎖定型**：「提醒 [特定身份] 的你」，用身份鎖定更精準的受眾

## 13. 過來人觀察框架

**結構**

```
[身份/場景] 久了，真的會發現一件事：
[一個扎心但真實的觀察]。

（展開說明，用具體經驗佐證）
```

**邏輯**：「久了」三個字自帶時間份量——這不是理論，是實戰心得。一句扎心觀察就能引發大量共鳴。力量來自「你還沒走到這一步所以不知道，但我走過了告訴你」的視角差。

**適用場景**
- 職涯心得（工作 N 年、帶團隊久了、創業久了）
- 專業洞察（寫程式久了、做設計久了、教書久了）
- 生活觀察（獨居久了、健身久了、早起久了）

**撰寫重點**
- 觀察要「扎心但不負面」——是洞察，不是抱怨
- 避免過度亢奮的推銷感，採用「過來人的冷靜分享」或「專業提醒」語氣
- 一篇只講一個觀察，聚焦才有力量
- 可以不給解法，光是「點破」就夠有價值

**變體**
- **反直覺型**：「[身份] 久了才發現，[大家以為的事] 其實根本不是那樣」
- **清單型**：「[身份] 久了，這 5 件事我不再做了」

## 14. 連續執行轉變框架

**結構**

```
[你在執行的習慣] 連續 [具體時間]，我就像變了個人：

精簡列點（擇一角度展開）：
- 你如何執行（具體方法）
- 為什麼該執行（原因和好處）
- 怎麼辦到的（克服困難的過程）
```

**邏輯**：「連續 X 個月」是可驗證的承諾，比「我覺得 XX 很重要」有說服力 100 倍。「像變了個人」製造好奇心——到底變了什麼？列點回答這個好奇心。

**適用場景**
- 生活實驗（早起、冥想、運動、閱讀）
- 專業挑戰（每天寫文、每天練技術、每天學英文）
- 任何「持續做一件事帶來改變」的主題

**撰寫重點**
- 時間要具體（「連續兩個月」而不是「一段時間」）
- 列點只選一個角度展開，不要 how + why + what 全塞
- 變化要具體到「別人看得出來」的程度
- 與 #3「習慣累積框架」的差異：#3 是時間軸敘事（第1天→第N天），本框架是「結果導向」的精簡列點

**變體**
- **Before/After 型**：先列「之前的我」再列「現在的我」，對比更強烈
- **數據型**：加入具體數據（閱讀量從 X 變 Y、體脂從 X 降到 Y）

## 15. 雙元自介框架

**結構**

```
如果要我用一句話介紹自己，我會說：「有兩件事會讓我 [感官動詞]——一個是 [A]，另一個是 [B]。」

[接著分兩段分別講 A 和 B，最後合流到一個共同點]
```

**邏輯**：開場用「二擇」強行讓讀者承諾一種認識你的方式。大腦喜歡對稱結構，兩個具體的熱愛比一句「我是多才多藝的人」記得更牢。後續所有內容都收斂回這兩個主題，不會失焦。

**適用場景**
- 自我介紹（求職信、自介信、品牌自介、演講開場）
- 職涯故事（把兩個看似無關的領域串起來）
- 個人品牌定位（解釋為什麼做兩件事不衝突）

**範例**

> 如果要我用一句話介紹自己，我會說：「有兩件事會讓我眼睛發亮——一個是電影，另一個是棒球。」這兩件事都不是我「為了工作而培養的興趣」，而是從小到大一直跟著我、塑造我如何理解世界的方式。

**變體**
- **三元版本**：「三件事會讓我⋯」但超過 3 個就不要用
- **職涯+興趣版**：「兩個身份」（工程師+球迷、律師+登山者）
- **對立版**：「一個是理性的 X，一個是感性的 Y」

## 16. 專業頭腦 + 愛好者心合體框架

**結構**

```
我會對 [興趣領域] 這麼著迷，有一部分是因為我是一個 [專業身份]。
過去 [年份] 我做的事情是 [專業工作描述]。
所以當我開始 [進入興趣領域的行動]，我發現一件事——
「[專業能力] 和 [興趣特質] 其實是同一件事：兩者都在追求 [共同點]。」
```

**邏輯**：把「你的專業」和「你的熱情」串成**同一件事**，而不是兩件並列的事。這個框架解決「為什麼你值得信任去做這件事」的問題——因為你不是從零開始的業餘者，你是帶著專業視角進入一個熱情領域。

**適用場景**
- 跨領域求職（技術背景 + 非技術熱情）
- 轉職故事（舊身份 → 新身份的合理橋接）
- 副業自介（為什麼本業會幫助副業）

**範例**

> 我會對棒球這麼著迷，有一部分是因為我是一個工程師。過去八年我都在做資料工程與後端開發，每天的工作就是把看似複雜的事情用數據和邏輯拆解成可以討論、可以驗證的東西。所以當我開始追 MLB、讀那些進階數據的時候，我發現一件事——「工程師的頭腦」和「球迷的心」其實是同一件事：兩者都在追求「為什麼」，兩者都相信數字背後有故事。

**可套用模板**
- 設計師的眼睛 + 烘焙愛好者的手 → 都在追求「比例與層次」
- 律師的邏輯 + 登山者的身體 → 都在追求「風險與決斷」
- 老師的耐心 + 父母的心 → 都在追求「看見成長的瞬間」

**變體**
- 反向版：先講興趣，再帶出「因為我是 X 所以我看得比別人多」
- 收尾加一句「這是一份我意想不到的禮物」強化情感

## 17. 「多一位 X = 多半個 Y + 半個 Z」價值論述

**結構**

```
對於 [目標對象]（尤其是小團隊/小公司）來說，
多請我一個 [主身份]，等於同時多了半個 [副身份 1] + 半個 [副身份 2]。

[具體場景 1：當你需要 A 時⋯]
[具體場景 2：當你需要 B 時⋯]
[具體場景 3：當你需要 C 時⋯]
```

**邏輯**：把多面手背景轉換成**對目標對象的具體價值**。不是列能力，而是把「多出來的能力」量化給對方看。關鍵是「半個 X + 半個 Y」這個公式讓抽象的跨領域能力變成可計算的槓桿。

**適用場景**
- 小團隊求職（新創、5-10 人團隊、外包）
- 接案/顧問定價論述
- 多面手品牌定位（為什麼跨領域是優點不是缺點）

**範例**

> 如果 Rebas 某天想在 IG 寫一篇「為什麼今年象隊的配球策略變了」，我可以下班後自己動筆寫；如果想做一波新指標上線的行銷活動，我可以幫忙設計漏斗與內容；如果想把 release note 寫得像球迷會想讀的短篇故事，我會第一個舉手認領。這是我作為「一位工程師」之外，能帶給小團隊的隱藏槓桿——一種「多請一個人，等於多了半個產品 + 半個內容夥伴」的價值。

**撰寫重點**
- 「半個 X」要選對方真的會需要的能力，不要自顧自列
- 具體場景要用「當你⋯」開頭，帶對方進入想像
- 避免出現在大公司求職信裡（會被視為「不專注」）

**變體**
- **付費版**：「聘一位顧問 = 節省你聘三個職位的成本」
- **自謙版**：「我不是最強的 X，但我可能是最能跨界的 X」

## 18. 家族情感錨 → 現代橋接框架

**結構**

```
[童年/家族場景：具體畫面]
[長輩或家人說過的一句話]
[當時不懂，但長大後才知道那是 XX]
[現在我用現代的視角/工具延續這件事]
```

**邏輯**：用長輩的直覺或童年記憶作為情感起點，橋接到現代專業領域。這讓你的熱情看起來**不是最近才培養的**，而是有時間感、有家族感、有延續性的。讀者相信長遠的熱愛勝過短暫的興趣。

**適用場景**
- 求職信開場（建立情感與時間感）
- 品牌故事（為什麼我做這件事 = 因為從小⋯）
- 專題文章的引子（把硬題目變軟）

**範例**

> 我從小跟著外公和爸爸一起看二代象——那個年代還沒有進階數據，我們只能盯著電視手抄打擊率和防禦率。我外公會跟我說「這個打者在 RISP 表現比較好」、「這個投手第三輪會掉」——他不知道那叫做 wRC+ 或 Times Through Order Penalty，但他用四十年看球經驗講出了現代分析學在驗證的事。那是我第一次理解：棒球的數據不是冰冷的數字，而是球迷把熱情萃取出來的語言。

**撰寫重點**
- 家族場景必須**具體到可視化**（老電視、手抄筆記本、某個具體地點）
- 長輩的話要**引述原話**或接近原話，不要抽象概括
- 「當時不懂，後來才知道」是這個框架的情感轉折點
- 禁忌：不要編造家族故事；只用真實經歷

**變體**
- **朋友版**：把家族換成童年好友或國小老師
- **反差版**：長輩說的話當時覺得老派，現在才發現是金句

## 19. 「這就是我國中時想做的東西」情感表達

**結構**

```
當我看到/聽到/用到 [某個產品或公司]，
我腦中第一個念頭是：「[情感化的呼喊]。」
[為什麼這句話說得出來——因為我從以前就⋯]
```

**邏輯**：表達「終於遇見對的東西」的情感強度。關鍵是**具體到某個童年/青春時期**，而不是「我一直都想」這種抽象說法。有時間感的情感比現在式的情感可信 10 倍。

**適用場景**
- 求職信「為什麼是這家公司」段落
- 產品推薦文（為什麼我會買）
- 訪談故事（為什麼你做這件事）

**範例 1**

> 當我點進去之後就回不來了。那時候我腦中第一個念頭是：「台灣終於有人用球迷的語言把這些東西做出來了。」這就是我國中時想做的東西。

**範例 2**

> 我第一次打開 Notion 的時候，心裡冒出來的話是：「我大學時就想要有這種東西。」

**範例 3**

> 當我第一次看到 GitHub Copilot 可以幫我補整段函式的時候，我坐在螢幕前笑了出來——這就是我研究所時偷偷想過「要是有這種工具該多好」的東西。

**變體**
- **遺憾版**：「可惜這個東西晚了十年才出現」
- **情感加強版**：加上具體的時間點（「這就是我 2015 年想做的東西」）
- **謙遜版**：「我曾經想做但做不出來的東西，你們做到了」

**禁忌**
- 不要用在大公司求職信（會顯得太情感用事）
- 不要連續用兩次（一封信一次就好）
- 不要對完全陌生的公司用（你得先建立具體的「為什麼」）
